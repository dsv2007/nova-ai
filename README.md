## 🚀 Quick Start

### Clone Repository
```bash
git clone https://github.com/dsv2007/novamind-cloud.git
cd novamind-cloud
```

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production
```bash
npm run build
npm start
```
